# Family Mudi Bhandar

A responsive Bengali-language grocery storefront for **Family Mudi Bhandar**.

## Current features

- Product catalogue with category filters and search
- Shopping list basket with quantity counts
- Copyable market list
- Responsive mobile and desktop layout

## Before publishing

The shop address, phone/WhatsApp number, confirmed product list, prices, delivery details, and payment options have not been provided yet. The catalogue is an editable starter list and does not show invented prices.

This repository contains a static website in `index.html`. It is not deployed yet, so there is no live website URL at this time.
